Why a v2

The original Running Form Robot worked: it followed a runner outdoors and reported stride rate in real time. But the gait analysis came from motion-capture software I integrated rather than wrote, so the most important part of the system was a black box. The hardware has since been retired, too.

v2 rebuilds the system in software, with every step written by me. Building it in simulation means the whole pipeline can be developed, tested, and shown without a rover or a runner, and each piece can be checked against a known answer before moving on.

The plan

v2 is a gait-analysis pipeline built from ROS 2 nodes in C++, each handling one job and passing data to the next:

  • Simulated leg. A leg model (URDF) running in Gazebo, so there is a "runner" whose motion is known exactly.
  • Joint control. PID control of the leg's joints through ros2_control, so the model can be driven through a realistic stride.
  • Pose tracking. Computer vision (OpenCV) that measures stride rate and joint angles from running video, the job v1 handed to outside software.
  • Form feedback. Comparing the measured gait to target ranges and reporting where it falls outside them.

Because the simulated leg's true motion is known, the tracking can be checked directly: if the vision code reports a stride rate or knee angle, it can be compared to what the leg actually did.

What works now

The ROS 2 Jazzy workspace is set up on Ubuntu 24.04, and the first C++ node is running. It publishes a simulated knee angle 50 times a second, swinging between 5° and 65° at 1.5 strides per second. Plotting it live in rqt_plot confirmed both the range and the stride frequency match the model. This node is the stand-in runner the rest of the pipeline will be built against.

Roadmap

  • Done: ROS 2 and Gazebo environment setup
  • Done: first C++ node, a simulated knee-angle publisher
  • Next: leg model (URDF) running in Gazebo
  • PID joint control with ros2_control
  • Pose tracking with OpenCV to measure stride rate and joint angles
  • Form feedback against target ranges
